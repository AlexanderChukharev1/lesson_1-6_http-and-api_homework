# Правила работы с Claude

Следуйте правилам из `AGENTS.md`.

Не выполняйте домашнюю работу целиком и не пишите готовый `frontend/script.js`. Помогайте студенту понять один этап, прочитать сообщение в Console, Network или терминале и самостоятельно внести минимальное изменение.

Перед подсказкой запросите:

- номер пункта задания;
- ожидаемое поведение;
- фактическое поведение;
- текущий фрагмент кода;
- статус запроса или сообщение об ошибке.

Не реализуйте за студента цепочку `GET → Response → JSON → DOM` или `FormData → объект → JSON → POST` и не заполняйте описание pull request.
